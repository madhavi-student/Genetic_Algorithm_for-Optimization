# Genetic Algorithm for Optimization

## Project Description
This project implements a Genetic Algorithm using Python
to solve an optimization problem.

## Objective
To find the maximum value of the function f(x) = x^2,
where x ranges from 0 to 31.

## Technologies Used
- Python
- Visual Studio Code

## Algorithm Steps
1. Initialize the population.
2. Calculate the fitness of each solution.
3. Select the parents.
4. Perform crossover.
5. Apply mutation.
6. Repeat the process for multiple generations.
7. Display the best solution.

## Result
The optimal solution is x = 31.
The maximum fitness value is 961.
